# Automated SOC Project (Cloud-Based)

Cloud-based Automated Security Operations Center (SOC) graduation project focused on lightweight detection, alert forwarding, and automated response workflows.

## Repository Structure
- `docs/` — Architecture diagrams, implementation plan, and execution screenshots.
- `wazuh-config/` — Detection rules and alert integration settings.
- `shuffle-workflows/` — Automated SOAR response workflows.
- `attack-simulation/` — Lightweight scripts for generating test security events.
